# 積算差動抗力の定義と適用限界

瞬間の密度差が大きくても、全衛星が同じ構造を順に受ければ積算差は相殺される。一方、積算差が長く残ると平均軌道の速度差になり、間隔が蓄積して変わる。終了時の積算差だけで、その途中にできた位置ずれまで消えたとは言えない。

## 1. 中心となる5量

1. `J_rho,j(t)=integral_0^t rho_j(tau) d tau`、隣接差 `Delta J_rho,i=J_rho,i+1-J_rho,i`。単位kg s/m³。主要表は**全gap・全時刻の最大絶対値**で、終了値とは別に保存する。
2. `J_drag,j=integral a_drag,j dt`、隣接差 `Delta J_drag,i`。単位m/s。負の沿軌道抗力を積分するためJ_drag自体は通常負になる。
3. `v_i=de_i/dt=a_ref*(n_i+1-n_i)`。単位m/s。連続してNRLMSISが作用する期間では、「外乱が終わった後の一定残留速度」とは呼ばない。
4. `e_max=max_(i,t)|e_i(t)|`。主要誤差は従来どおり `e_i=a_ref*(lambda_i+1-lambda_i)-100000`。
5. `RMS=sqrt(mean_(全保存時刻・全20gap)(e_i²))`。各gapのRMS、終了時最大値も保存する。終了誤差は収束判定ではない。

100 km比は `e[m]/100000*100`。100 mは0.1%である。

## 2. 元モデルで導ける関係

面積が全LOWで一定の場合、既存coreは

`da_j/dt=-rho_j*Cd*A_LOW/m*sqrt(mu*a_j)`

`dlambda_j/dt=sqrt(mu/a_j³)`

を解く。したがって

`sqrt(a_j)=sqrt(a_j(0))-Cd*A_LOW*sqrt(mu)/(2m)*J_rho,j`

が成り立つ。密度の積算量が大きいほど軌道半径が小さくなり、その衛星の平均角速度が増える。保存半径からこの積算量を復元し、保存密度の直接積分で照合する。これは元ODEの恒等関係であり、独立な観測から因果を証明したものではない。

抗力加速度は `a_drag=-rho*Cd*A_LOW*mu/(2m*a)` なので、

`J_drag=sqrt(mu)*(1/sqrt(a(0))-1/sqrt(a(t)))`

になる。高度低下と同じ軌道状態から得る診断量である。円軌道近似・小変化では `v_i ≈ -3 Delta J_drag,i`。**通常の速度を直接3倍する操作ではなく、抗力で半径が下がって平均角速度が増えることを表す。** 元モデルの角速度からの厳密な評価を主要値とする。

初期半径が等しく、小さい差を線形化すれば

`v_i(t) ≈ C Delta J_rho,i(t)`、`C=3 Cd A_LOW mu/(2m a_ref)`

`e_i(T)-e_i(0) ≈ C integral_0^T Delta J_rho,i(t) dt`

となる。最後の式は、過去にできた速度差が続いた時間も位置ずれに効くことを意味する。同じ終了時積算差でも、いつ差が生じたかによって間隔誤差は異なる。3期間の最大値を並べただけで統計的相関を主張しない。

## 3. 積分・数値誤差

半径から復元するJ_rhoは**保存軌道に整合する有効積算値**である。RK4の2秒ステップ誤差や浮動小数点誤差も含む。密度10秒保存値の台形積分も併記し、3時間Ap更新と日付境界では旧入力側の密度を別に評価して、ジャンプを誤って平滑化しない。

元RK4は境界直前のステップの最終stageで新しい入力を読む。その一次的な積分偏りは `step/6*(rho_right-rho_left)` と見積もり、間隔への影響を参考として記録する。これは厳密な数値誤差上界ではない。元の積分器は変更しない。

密度120秒キャッシュの直接評価チェックでは、共通密度の相対誤差だけでなく**隣接差とその積算誤差**も確認する。直接再評価は同じ保存軌道上なので、真の直接評価軌道へのfeedbackまで解いた検証とは区別する。

## 4. 間隔定義とモデルの限界

補助量は `0.5*(a_i+a_i+1)*(lambda_i+1-lambda_i)-100000`。現在半径の物理弧長の近似で、全衛星が共通に高度低下しても短くなる。主要の固定基準半径誤差と混同しない。高精度の瞬間3次元距離ではない。

NRLMSIS 2.0は[平均的な観測挙動を表す経験モデル](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2020ea001321)であり、個々のTAD・局所構造の実現を復元するものではない。緯度・経度・WGS84高度は、固定傾斜51.6度、RAAN0、lambdaを軌道位相とする既存変換から計算する。UTC≈UT1で地球自転ERAを使用し、J2・軌道面歳差・風の力学モデルは含まない。

epochが変わると、同じRAAN・初期位相でも初期の地理経度・地方時は変わる。太陽活動・季節も異なる。期間の比較は**宇宙天気環境の比較**であり、地磁気活動だけの純粋な因果効果や全軌道面の上限を与えない。

各runは選定epochで全機を同じ初期半径・目標位相差から開始する。それ以前の大気場を受けた軌道履歴は再構成していない。したがって初期位相と初期速度差0も結果へ影響し得る。強嵐期の誤差が小さいことを、強嵐一般で差動抗力が小さいという結論にしない。

## 5. 観測の積算方法

GRACE A/Bでは、有効な隣接標本間だけを台形積分する。非ゼロflag、欠測、100秒超gap、NRLMSIS入力ジャンプ付近をまたがない。支持区間の合計は、1日間全部の積算差とは異なる。欠測中をゼロと仮定したわけではない。

400 km規格化は `rho400=rho_obs*MSIS2(400km)/MSIS2(observation height)`。背景に対する相対偏差が高度によらないという仮定を置く。重力波の高度依存やモデル誤差まで取り除く方法ではない。

同時刻比較、近傍同地点通過への時間シフト比較を別に保存する。地理位置の差や3度平均・校正差が残るため、空間と時間を完全分離したとは言わない。支持区間の密度差を平均除去して積算値をゼロにする処理は行わない。

不確かさの表示は、製品に付属する個別密度誤差を400 kmへ同じ比率で移し、A/Bの和を全時間相関させた包絡である。信頼区間ではなく、欠測・背景モデル・高度規格化の誤差まで含む完全な誤差予算でもない。一定の衛星間校正ずれでも積算差が生じるため、それを説明できる相対校正ずれの大きさも報告する。
