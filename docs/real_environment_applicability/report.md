# 研究判断用サマリー

## 1. 一番重要な結論

NRLMSIS 2.0・全LOWの60日最大誤差は、静穏側73.2 m、活動期113.1 m、強嵐期15.0 mでした。100 mを超える環境はありますが、km級ではありません。「100 km列には制御が必須」という一般的主張は支持されません。精度要求によって必要性が変わる領域なので、制御性能の最適化より適用限界を先に調べるべきです。実観測から100 km間隔の60日誤差まで確定したわけではありません。

## 2. PHASE 1：TADの時間変化

波の周期や移動速度は確認できましたが、個別構造の振幅が4〜5分でどれだけ変わるかを観測で拘束できませんでした。「5分で密度増加」という重要な例は数値モデルの引用でした。不変と証明したのではなく、任意の寿命を置く根拠がないため、新しい時間変化Gaussian計算は見送りました。

## 3. PHASE 2：宇宙天気だけで事前選定

| 環境・開始日 | 最大間隔誤差 | max abs(ΔJρ) [kg s/m³] |
|---|---:|---:|
| 静穏側・2024-01-01 | 73.2 m | 6.23e-11 |
| 活動期・2024-03-01 | 113.1 m | 9.70e-11 |
| 強嵐期・2024-05-01 | 15.0 m | 7.26e-11 |

ΔJρは隣接衛星の累積密度差で、表は全時刻の最大です。終了値だけで位置ずれは決まらず、その差が続いた時間も効きます。太陽活動・季節・初期地方時も異なるため、地磁気活動だけの効果とは言いません。補間の追加監査では最大約1.08 mの履歴差が見積もられ、全履歴1%基準を満たさない期間がありました。細かい桁を物理的精度として扱いません。

## 4. PHASE 3：観測から言えた範囲

キャッシュ済みGRACE A/Bから、地磁気指標で選んだ各1日の同時刻差・近傍同地点通過差・有効区間の積算差を取得しました。ただし各値は付属密度誤差の積算包絡内で、欠測もあります。持続する実密度差としては識別できません。約220 km対・3度平均のデータを100 kmの直接証拠には使いません。

## 5. 制御研究へ戻るべきか

**制御最適化を主題から外す（要求境界・適用限界の確認を先行）。** 事前基準ではCに近い判定です。研究の中心は当面「熱圏密度変動の影響と差動抗力制御の適用限界」とします。実環境で永久に制御不要と証明した、という意味ではありません。

## 6. 次の作業

2. 60日補間の積算精度を改善し、必要なら代表ケースのみ180日へ延長する。
3. GRACE A/Bの相互校正と欠測の扱いを整え、実積算差を識別する。
