# PHASE 1：列通過中の時間変化に関する判断

**結論：時間不変TADを1回通過するだけで大きな長期誤差を作る研究方向は終了する。今回、新しい振幅成長・減衰モデルは実行しない。** これは「実際の全TADが5分間不変」と証明できたからではない。確認した原典から、400 km級の個別構造について、4〜5分間の振幅包絡の変化率を観測で拘束できなかったためである。短い寿命を仮定して積算抗力差を作る根拠は得られなかった。

## そこから言えること

周期14.4分の波では、5分間に固定地点の位相は大きく変わり得る。しかし、形が変わらず移動する波であれば、その位相変化は既存の外乱伝播速度に含まれる。これをさらに任意の `A(t)` に置き換えると、移動と成長を混同する。

既存の1回通過計算では、地球固定と730 m/sのTADの後に差動積算曝露がほぼ消えた。**今回の根拠では、この結果を覆すための新しい時間窓を追加しない。** 継続的・全球的な経験大気場の評価はPHASE 2で別に実施する。

## まだ言えないこと

波の干渉、生成領域の移動、急変する加熱、風、異なる軌道高度や緯度履歴が差動積算抗力を残さないとは言えない。必要なのは、同じ構造を追跡できる複数衛星観測から、振幅包絡の変化と単なる位相移動を分ける制約である。単一衛星の沿軌道密度履歴を5分間の同地点観測として扱わない。
