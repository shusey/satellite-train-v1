# 評価量の意味と定義

## 位置誤差と間隔速度

位置誤差は「実際の間隔が100kmの目標から何mずれたか」、間隔速度は「そのずれが毎秒どれだけ増減しているか」である。個々の衛星の軌道速度ではない。

既存の円軌道・軌道平均モデルをそのまま使う。基準半径をa0、衛星の非折り返し位相をλ、長半径をaとすると、

`e_i = a0*(λ_(i+1)-λ_i-d/a0)`、`v_i = de_i/dt = a0*(n(a_(i+1))-n(a_i))`。

これは、一定の基準半径で位相差を距離へ換算し、隣の衛星との平均角速度差を間隔速度へ換算するという意味。実装で保存されたe/vを使用し、粗い数値差分からvを作り直さない。

- 最大誤差：全保存時刻・全20間隔の`max(abs(e))`。
- 全期間RMS：`sqrt(mean(e_i(t_k)^2))`。時刻と間隔の両方を平均する。10秒等間隔の保存サンプルをすべて使う。
- 瞬間RMS：各時刻で20間隔だけを平均。図の時間履歴はこちら。
- 間隔別RMS：各間隔について全時刻を平均。
- 終了時最大誤差：最後の保存時刻だけの最大値。収束判定とは別の量。

## 制御判定量qとKpの役割

Kpは位置ずれを判定量へ換算する係数。係数を小さくしただけでも位置由来の判定量は小さくなるので、q_Pの大小を物理的な誤差の大小と混同しない。

`p_i = Kp*e_i + Kd*v_i`として、実装は

`q_1=p_1`、`q_j=p_j-p_(j-1) (2≤j≤20)`、`q_21=-p_20`。

つまり内側衛星は左右の間隔の信号差を見て、端部は接続する1間隔を見ている。この演算をBと書く。

`q_P=Kp*B*e`、`q_D=Kd*B*v`、`q=q_P+q_D`。

これは、位置ずれと間隔速度を同じ近傍差分で処理し、足し合わせてHIGH/LOWを選ぶという意味。

速度項が0という同一状態の参考計算では、HIGHに必要な`B*e=h_on/Kp`は0.3/1/3倍で233.28/69.984/23.328m。これは近傍差分B*eの条件であり、全列最大誤差の許容値ではない。実際には符号付きD項が加わるので、この数値をそのまま起動誤差の予測に使わない。

LOW・指令可能・`q≥h_on`でHIGH指令、HIGH・指令可能・`q≤h_off`でLOW指令。slew中とdwell中は新しい指令を出せない。既存の判定・同時指令・イベント順序を変更していない。

## 起動時に蓄積していた位置誤差

「どの程度ずれてから制御が反応したか」を、判定量ではなくm単位で確認する。

各HIGH指令と、その指令につながった最後の途切れない上向き閾値横断の保存サンプルについて、全列最大誤差、全列瞬間RMS、起動衛星に接続する1〜2間隔の最大絶対誤差を保存。接続間隔の符号付きe/v、B*e、B*v、P増加率、onまでの残り距離も保存する。全配列は元runのNPZを参照する。

「下からの横断」と「LOW完了時にすでにon以上」を区別する。横断と指令の間にLOW側dwellがある場合、2つの時刻と状態は異なる。

全指令、全LOW後に活動が始まる指令、固定時間間隔で分けた時間群の起点を別集計する。伝播中の多数の指令を、長い静穏後の新しい反応と同一視しない。

## L-H-Lと残留状態

L-H-L cycleは、1機がLOWからHIGHへ移り、再びLOWへ戻る1往復。LOWへ戻るslew完了直後の保存状態を終了状態とする。HIGHのまま、またはLOWへ移行中のものは完了回数に含めない。

残留相対速度は、往復終了後にも間隔へ残っている速度差。`V_res=max(abs(v_i))`を主指標とし、速度RMS、絶対速度中央値、符号付き間隔別配列も保存する。起点・参加衛星の接続間隔を使った統計と、全20間隔の統計を区別する。

`Q_D_res=max(abs(q_D,j))`は判定量としての残留速度項。Kdは固定だが、隣接差分を取っているのでV_resと同じ量ではない。

局所cycleの完了時には、近傍の別衛星が作動中の場合がある。列全体がLOWで保留指令もない境界を別に評価する。すべての終了状態のe/v/q_P/q_D/q/mode配列を`cycle_end_states.npz`へ保存し、CSVの行番号で参照する。

## 誤差が増える方向か、戻る方向か

同じ残留速度でも位置誤差との向きによって、その後の誤差が増える場合と減る場合がある。

`e_i*v_i>0`は誤差二乗を増す方向、`<0`は減らす方向、`=0`は中立。全間隔での割合を保存する。

`悪化の加重割合 = sum(max(e_i*v_i,0))/sum(abs(e_i*v_i))`。

これは、誤差変化の大きい間隔を強く数えた悪化方向の割合。1へ近いと主に誤差が増す方向、0へ近いと主に戻る方向。分母0はnull。単純な符号割合には丸め誤差に近い値も入るため、両方と符号付き配列を併用する。工学的なゼロ判定を新しく仮定していない。

## 次回切替の簡易予測

列全体がLOWで作動が止まっていても、残留速度があれば位置誤差は蓄積する。予測は、この速度がほぼ変わらないとして「次に判定量がHIGH閾値へ届くまで」を計算するもの。

`d(q_P)/dt = Kp*B*v = (Kp/Kd)*q_D`。

これは、残った間隔速度が位置項を時間とともに動かすことを意味する。同じe/v状態でもKpを変えると、初期P項とその増加率がともに変わる。実際の実験では切替履歴と状態そのものも変わる。

`ΔT_cross = (h_on-q_P(t0)-q_D(t0))/(Kp*B*v(t0))`。

分子は閾値までの残り距離、分母はそこへ近づく速さ。onより下で増加率が非正なら将来の上向き横断を予測しない。すでにon以上なら、dwell解除時までonを保つかも確認する。予測指令時刻はLOW側の指令許可時刻以降の10秒制御格子へ切り上げる。

各衛星から最早候補を選び、次回の実測HIGH指令時刻・衛星と比較。予測時点以降に介在指令がない、作動・保留がない、対象D項の変動が10%以内などの既存条件を満たす場合だけ「有効」とする。これは後処理の判定設定で、物理モデルの入力ではない。

予測誤差は実測−予測、相対誤差はそれを実測待ち時間で割る。予測時刻が観測外、実測次回がない場合は未検証と明記する。一定D近似による予測は永久収束や安定性の証明ではない。

## P優勢・D優勢

どの判定成分が大きかったかを整理する。P優勢は位置由来、D優勢は速度由来の絶対値が大きいという意味。

`abs(P)≥2abs(D)`をP優勢、`abs(D)≥2abs(P)`をD優勢、他を混合とする。反対符号、相殺率、D絶対値比を別保存。絶対値の分類は因果寄与率ではない。特に群の起点と後続の伝播指令を区別する。

## dwellとHIGH量

dwellは姿勢変更が完了してから次の指令まで待つ時間。HIGHとLOWの両側に300秒を適用する。HIGHが終わってから最初にLOWを指令できる時刻を「帰還の許可時刻」と呼ぶ。

HIGH開始後に初めてq≤h_offになった保存時刻、その条件が許可時刻より前に観測されたか、許可時刻にも条件を満たすかを別に記録する。一度off以下でも、許可時刻までに再上昇する場合がある。

同一衛星のLH開始→次LH開始の理論下限は`2*(120+300)=840秒`。slew2回と両姿勢のdwellを待つため。実測がこの下限に一致した回数、横断後にLOW側dwellを待った指令数も保存する。

HIGH安定時間は、HIGH姿勢完了からLOWへのslew開始までの時間。HIGH相当時間（HIGH equivalent time）は、slew中の面積増加もHIGHの時間へ換算した量：`integral((A-A_LOW)/(A_HIGH-A_LOW) dt)`。全列合計は衛星・秒。300秒保持と120秒slewの完了1往復なら420衛星・秒になる。

## 高度損失・有限観測・群分け

追加高度損失は、同じ外乱で全LOWだった場合に比べてどれだけ余分に高度を失ったか。

`extra_loss=mean_j(a_allLOW,j(t)-a_control,j(t))`。同一時刻・21機平均、正が追加損失。円軌道モデルでは長半径差と高度差が同じ。初期高度からの全抗力損失とは別の量。

回復時刻は、誤差・速度の許容条件を指定時間維持した最初の区間。settlingは、その後観測終了まで逸脱と新しい切替がない区間。既定50m・1mm/s・1800秒は従来設定で、後処理で変更可能。確認できた期間も保存し、永久収束と解釈しない。

時間群は既存14日baselineから得た分類間隔を固定して分ける。全LOW後の活動区間は、重なったHIGH指令〜LOW完了の区間をまとめて分ける。前者は短い再応答をまとめる場合があり、異なる条件の群番号を同じ物理cycleとして対応させない。
