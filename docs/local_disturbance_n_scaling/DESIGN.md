# 実行前に固定した比較条件

目的は現行hybrid DD制御の有限時間・局所入力応答を衛星数で比較すること。
制御設計・最適化・厳密なstring stability証明は行わない。

- N = 11, 21, 51, 101, 201, 301。各Nでnominal/disturbedの2軌道を独立に積分。
- 基準は `configs/baseline.yaml`。dwellはHIGH/LOWとも300 sの既存基準。
  H150-L300等の研究候補へ基準を置き換えない。
- 全軌道で初期半径を同一、固定基準半径上の初期間隔を100 kmとする。
  B倍率は全衛星1、初期位相・半径分散、ノイズは0。
- 密度は既存exponential高度則。Gaussian密度外乱は無効。
  NRLMSISの緯度・経度・時刻差による差動成分も今回加えない。
  高度が応答によって変化したときの背景密度変化は既存モデルのまま。
- Kp = 1/21600²、Kd = 2/21600、h_on = 1.5e-7、h_off = 1.4e-7。
  control 10 s、slew 120 s、HIGH/LOW dwell 300 s、delay 0。
- mass 4 kg、Cd 2.2、LOW .01 m²、HIGH .03 m²、高度400 km。
- 正の一般化node入力dを中央衛星へ1回のみ与える。
  d = d/dt[a_ref n(a)]への追加入力、単位m/s²。
  これはCartesian加速度や観測された密度擾乱そのものではない。
- 最大1e-6 m/s²、開始10800 s、継続3600 s、raised cosine。
  全N共通、積分値0.0018 m/s。観測由来の標準波形は既存コードにないため
  原因を分離する探索入力として新設した。現実性の主張はしない。
- 半径方程式への追加項は -2 a d/(3 a_ref n(a))。
  したがってgap加速度への直接寄与は厳密にw_i=d_(i+1)-d_i。
  中央ID c=(N+1)/2のとき、1-based edge c-1が正、edge cが負。
- 最大RK4刻み2 s、保存10 s。全Nで同じ14日を観測、終盤窓は最後の3日。
- 14日は初回伝播と再切替を見るための有限な探索期間。
  終了時最大値、未到達の列端は時間打切りとして報告し、飽和とみなさない。
- 主要評価はdelta e=e_disturbed-e_nominal。raw eもローカル保存。
  中央に接続する左右のgapをr=0、その外側をr=1,2,...とする。
- 回復候補はパルス終了後、全gapの|delta e|<=5 mが観測終了まで続き、
  少なくとも1日確認できた場合のみ。永久収束とは呼ばない。
- 伝播の補助指標として追加誤差1 mへの初回到達を記録する。
  t_peakは再切替で後から更新され得るため初回到達時刻とは区別する。
- べき乗近似は両対数のR²>=0.95、正の傾き、6点で厳密な増加、
  peakの最大/最小比が1.01以上の場合のみ
  探索的な指数を提示する。条件不成立なら指数を解釈しない。
- 新しいゲイン、外乱振幅、追加N、観測期間の掃引は行わない。

機械可読の実行設定は `configs/local_disturbance_n_scaling.yaml`。
既存runは上書きせず、`outputs/local_disturbance_n_scaling_20261026/`へ保存する。
