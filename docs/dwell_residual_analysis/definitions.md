# dwellとcycle終了時の残留状態

## 変更範囲と固定条件

物理、制御、姿勢遷移、積分器は変更していない。変更する入力はdwellのみ
（150 / 300 / 600 s）。HIGHだけでなくLOW姿勢完了後の再指令待機にも同じdwellが適用される。
したがってこれは「dwell政策全体」の介入であり、HIGH保持時間だけを独立に変えた実験ではない。
Kp=1/21600²、Kd=2/21600、h_on=1.5e-7、h_off=1.4e-7、
制御周期10 s、slew120 sと他の条件は凍結24時間設定のまま。
これらのゲインは暫定値であり最適性を意味しない。

## gapと判定量

保存される隣接間隔誤差は e_i=a0(λ_(i+1)−λ_i−d/a0)、
間隔速度は v_i=de_i/dt=a0(n_(i+1)−n_i)。
速度の数値差分ではなく、既存保存配列 gap_rate_m_s を使う。
21衛星に対してgapは20本。p_i=Kp e_i+Kd v_i とすると
q_1=p_1、q_j=p_j−p_(j−1) (j=2,…,20)、q_21=−p_20。
P項は同じ差分演算にKp e、D項はKd vを入れたもの。符号付き全配列も保存する。

## 3種類の終了境界を区別

1. **local cycle**：各衛星のL→H指令と続くH→L指令を対にする。
   LOW姿勢完了後の最初の保存標本を終了状態とする。周囲衛星がまだ動作中でも記録する。
   未完了cycleは別途残し、終了状態を捏造しない。
2. **response group**：以前の14日イベントから定義済みの時間間隔
   80953.6935537842 sによる応答群を再利用する。300秒では既存waves.jsonを読む。
   長い群は複数のL-H-Lを含むので1周期とは呼ばない。
3. **quiet packet**：全衛星の[L→H指令, LOW完了]区間の重なりを合併する。
   連続活動が終わり、全衛星LOWかつ保留遷移なしになった境界。
   時間間隔閾値は用いない。短い休止後の伝播も独立したpacketとして残る。
   同時に新しい指令が出る境界は合併し、静穏境界と誤認しない。

終了時刻と標本時刻・ずれを別々に保存する。今回のイベント完了は保存10 s格子上なのでずれ0。
異なるdwellでは参加集合、背景状態、時刻、群の分割が異なる。
同じ番号を同一物理状態とみなした平均・周期比較は行わない。

## 残留指標

V_res_all=max_(全gap) |v_i| [m/s]。
participant / seed版は参加・起点衛星に接続する隣接gapの和集合上の最大値。
衛星自身の絶対軌道速度ではない。
Q_D_res_all=max_(全衛星) |q_D,j| [m/s²]。
participant / seed版は該当衛星node上の最大値。
own_q_D、予測最早nodeのq_D、実測次回nodeの終了時q_Dを符号付きで記録。

cycle_end_states.npzには各終了境界のe、v、q_P、q_D、q、modeを保存する。
CSVのend_state_rowで対応する。巨大なシミュレーションNPZと状態NPZはローカル保存。
CSV/JSONは代表値と衛星・gap番号のみ。source_sample_indexから元runにも戻れる。
localのE_nはその衛星のHIGH指令〜LOW完了の全gap最大値と接続gap最大値。
同時制御の影響を含む。own_extra_loss_active_incrementは当該衛星の全LOW比増分。
quiet/groupのE_nと高度増分はそれぞれ活動区間全体。

## 次回横断の簡易予測

同じ差分演算を使うため d(q_P,j)/dt=(Kp/Kd)q_D,j は運動学的恒等式。
しかしq_D一定は仮定であり、他衛星のパルスや軌道減衰によって破れる。
終了標本t0でq0=q_P0+q_D0、s=(Kp/Kd)q_D0 として、

q_pred(t)=q0+s(t−t0)

q0<h_onかつs>0の場合、
T_cross_pred=t0+(h_on−q0)/s。
既に閾値以上ならt0、閾値未満かつs<=0なら有限の上向き横断を予測しない。
LOW再指令可能時刻t_allowedを含め、

T_command_pred=10 ceil(max(T_cross_pred,t_allowed)/10)

とする。負の傾きで待機終了前に閾値を下回る場合、指令予測は無効。
全LOW境界では全nodeの候補から最早時刻を選び、実測の次回nodeを使って選別しない。
localでは同一衛星の次回L→Hと比較する。
誤差=(実測−予測)、相対誤差=(実測−予測)/(実測−t0)。
閾値横断の最初の保存標本と実際の指令時刻も別々に残す。

## 有効性と観測限界

評価窓で全LOW、保留/進行中遷移なし、介在指令なし、q_Dの相対変化<=10%、
有限予測が存在する場合に prediction_valid_on_observed_window=true。
10%は変更可能な**後処理の品質設定**であり物理・制御パラメータではない。
無効な予測の生の誤差と理由も削除しない。予測node一致も別のフラグ。
観測終了後に次回がないものはright_censoredとして扱い、未観測予測を的中と数えない。
単に切替が少ないこと、最後が全LOWであること、負のown_q_Dだけで永久収束と判断しない。
q_P変化と(Kp/Kd)∫q_D dtも記録し、位置蓄積の関係を検査できる。

## HIGHパルスとLOW帰還

指令、slew開始、完了を全て保存する。HIGH安定姿勢時間=LOW slew開始−HIGH完了。
HIGH等価時間=∫(A−A_LOW)/(A_HIGH−A_LOW)dt。
線形面積slewでは、完成したcycleの値はHIGH安定時間+両slew時間の半分。
遅延0、slew120 s、dwell支配なら270 / 420 / 720 s。
first_q_below_offはHIGH開始以降の最初のq<=h_off標本で、連続した滞在を意味しない。
HIGH完了時・LOW指令時のqも保存する。
HIGH完了+dwell後の最初の制御格子で帰還すればdwell_limited、
それより遅ければthreshold_limited_after_dwell。早いh_off通過だけではこの分類を決めない。
この分類のdwell_limitedは「最早許可格子で帰還」の意味であり、
最初のh_off到達がその格子と同時の場合には閾値制約も同時に働き得る。

## 精度・軌道コスト

全体RMS=sqrt(mean_(全保存時刻,全gap)(e_i²))。
時刻ごとのRMS(t)=sqrt(mean_(gap)(e_i(t)²))であり全体RMSとは異なる。
終了時最大誤差は収束判定ではない。
初期高度からの平均損失=mean_j[a_j(0)−a_j(T)]。
追加平均高度損失=mean_j[a_allLOW,j(T)−a_case,j(T)]、正が余分な損失。
共通初期値・外乱・評価時刻・衛星算術平均を使う。
全LOWは制御が無効なのでdwellが作用せず、既存300秒の同時刻全LOWrunを共用する。
平均追加損失増分は背景減衰による増幅も含み、HIGH等価時間に厳密比例はしない。
