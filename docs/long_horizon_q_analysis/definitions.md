# 長時間・再切替・q解析の定義

## 実装と変更範囲

物理モデル、制御則、姿勢状態機械、RK4、既存simulatorは変更していない。
`continuation.py` は保存端点のa、λ、イベントから姿勢状態・dwell時計を復元し、
既存の物理・制御・積分関数を呼ぶ小さな実行スケジューラである。
保存済み端点で処理済みのcommandを再評価せず、次の制御・出力時刻へ進む。
入力設定の変更はdurationだけ許し、既存の出力・制御時刻の共通境界からのみ再開する。
新しい出力先への保存のみ許す。旧runとそのNPZは変更しない。

21日・30日・45日・60日の制御あり／全LOW対照を、14→21→30→45→60日と継続する。
既存14日を再計算しない。全LOW対照も同じ外乱・観測時間で継続し、コスト基準を合わせる。
この機能は保存状態のない任意時刻からの再開や、ゲイン変更後の再開を保証しない。

## 制御判定量の厳密な分解

添字は1始まり。隣接間隔i=1,…,20の誤差・速度をe_i、v_iとし、

`p_i = Kp e_i + Kd v_i`

とおく。実装は、

- q_1 = p_1
- q_j = p_j − p_(j−1), j=2,…,20
- q_21 = −p_20

である。同じ線形演算をKp eとKd vに別々に適用し、q=q_P+q_Dとする。
保存済みqとの残差を自動検査し、10^-20 m/s²を超える場合は解析を停止する。
基準値はKp=1/21600²、Kd=2/21600、h_on=1.5×10^-7、h_off=1.4×10^-7 m/s²。
ゲインは暫定値であり、最適性は主張しない。

LOWでq≥h_on、HIGHでq≤h_off、かつcommand_allowedである場合にcommandを発行する。
slew中は新commandを発行しない。command delay=0、slew=120 s、完了後dwell=300 s。

**恒等式**：元モデルではde/dt=vなので、

`d(q_P)/dt = (Kp/Kd) q_D = q_D / 43200 s`

が成り立つ。q_Dが小さくても正に残れば、q_Pは時間積分により増える。
これは新しい線形化モデルの安定性主張ではない。
出力のconstant_D_ramp_predictionは、追加でq_Dを静穏区間開始時の値に固定した
再横断時刻の近似である。q_Dの変化や隣接衛星の切替があれば精度は保証しない。

## 波と局所cycle

波は時間的なイベント群であり、因果的に単一の進行波だという保証はない。
既存14日runのLOW→HIGH開始時刻の正の間隔を並べ、最大の間隔比で分離する。
群内最大9850 s、群間最小665330 s、比67.55の明瞭な分離がある。
その幾何平均80953.69 sを群分けの境界として固定する。
HIGH→LOWは同じ衛星の対応するLOW→HIGHへ付ける。
衛星別cycle番号で波を作ると、第2波で初めて反応した中央11番を誤分類するため避ける。

- 開始：群内最初のLOW→HIGH **slew開始**。delay=0なのでcommandと一致。
- 終了：対応する全HIGH→LOWの完了が観測された場合、その最終完了時刻。
- incomplete：未帰還・未完了cycleが残る場合。終了時刻はnull。
- E_n：活動区間[開始,終了]の全間隔の最大絶対誤差。未完了では観測端まで。
- 波中RMS：その区間の全保存サンプル・全間隔に等しい重みを与えた平方平均平方根。
- 開始前誤差：直前の保存サンプル（基準では10 s前）。
- 静穏区間最大：完了から次の波の開始直前まで。波中の最大と区別する。
- 起点候補：隣接衛星より早いLOW→HIGH開始時刻を持つ局所最小点。
- hop数：中央11番からの最大添字差。最初の切替衛星からの距離も別途保存する。
  グラフ上の距離は因果伝播距離の証明ではない。

第4群以降のように同一群内で各衛星が複数cycleを行う場合は、
「第4波が1回のL-H-Lを行った」と解釈しない。
`contains_repeated_local_cycles`、衛星別局所cycle番号、局所開始時刻間隔、7日区間統計を併用する。
群分け境界を0.5/1/2倍にした後処理感度も保存する。これは物理パラメータ掃引ではない。
境界によって後半の群数が変わる場合、群数や第5波以降の周期は一意でない。

## 伝播速度

既存switching_waveの中心から3 hop以内を除くフィットを再利用する。
左は7→1番、右は15→21番の初回LOW→HIGH時刻を使い、距離を時刻へ最小二乗で当てる。
3点以上、連続衛星、外向きに増加する到達時刻、R²≥0.8、正の有限速度を要求する。
これは**遠方の外向き枝の速度**であり、中央の遅い切替や複数cycleをまとめた単一front速度ではない。
基準24時間の左右20.2634 m/sと互換だが、二次波以降は全列を一つのfrontとして扱わない。

## 高度・状態・収束

元モデルの円軌道近似ではh=a−R_E。

- 初期からの平均高度損失：mean_j[h_j(0)−h_j(t)]。
- 追加平均高度損失：mean_j[h_LOW,j(t)−h_control,j(t)]。
  同一外乱・時刻の全LOWが基準で、正なら制御の方が低い。
- 波の活動中増分：追加損失(終了)−追加損失(開始直前)。
- 前波終了からの増分も別途保存。全LOWになった後も高度依存密度等により差は微変動する。

同一群内の重なった各衛星cycleへ群全体の損失を個別配賦しない。二重計上を避ける。
波終了時状態[e,v,a−mean(a)]と、前波とのL2差を単位別に保存する。
混合単位の生ノルムは使わず、補助の無次元ノルムのみ既存50 mと1 mm/sで規格化する。
その尺度はソフトウェア上の既存許容値であり、科学的な妥当性を保証しない。

T_recover/T_settleは既存evaluationの定義を維持する。
epsilon_e=1/5/10/50 m、epsilon_v=1 mm/s、W=1800 sを後処理だけで再評価する。
T_settleは最後の姿勢遷移完了後、観測端まで許容領域を保ち、W以上検証できた最初の時刻。
settled_by_tmaxとverification_horizonを併記し、永続収束とは解釈しない。

## 速度図と姿勢入力

最大絶対間隔速度は `max_i |v_i(t)|` であり、衛星そのものの絶対軌道速度ではない。
HIGH面積によってaの低下速度が変わり、n(a)の差が変わるため、隣接間隔速度も変化する。
数日表示では120 sのslewや数百秒の反応がほぼ縦線に見える。
最大を与える隣接間隔が交代すると曲線に折れも現れる。
元モデルはeやvをcommand時刻でリセットしておらず、この見た目だけで状態の不連続を意味しない。

戻りがdwell終了直後なら、1衛星1cycleのHIGH等価時間は
`slew/2 + dwell + slew/2 = 120 + 300 = 420 s`。
HIGH等価時間は面積超過を `(A−A_LOW)/(A_HIGH−A_LOW)` で積分したもので、
姿勢変更中の面積も含む。HIGH安定姿勢の300 sだけとは区別する。
繰り返すcycleの一定の入力パルス幅を理解する補助式であり、
dwellを変更すれば必ず安定化するという結論ではない。

全物理状態には抗力による単調なaの低下があるため、同じ完全状態に戻る厳密な周期軌道を
このデータから主張できない。limit cycle候補という場合も相対編隊状態の近似的な反復に限定する。
