# 今回追加した比較の定義

物理量・残留状態・予測・帰還条件の定義は[前回の定義](../kp_residual_analysis/definitions.md)を継承する。
新しい物理モデルや制御則は導入していない。

## 基準に対する改善と増加

`誤差改善率[%] = 100*(1-E(Kp)/E(1))`。

正なら基準1倍より誤差が小さく、負なら悪化。最大誤差と全期間RMSを別々に比較する。

`コスト増加率[%] = 100*(C(Kp)/C(1)-1)`。

正なら基準より多く切替や高度損失を使ったという意味。姿勢遷移数、追加平均高度損失、HIGH相当時間を別々に計算する。基準0の場合は割合を定義せずnull。

## 隣接条件で必要になった追加コスト

`誤差改善量 = E(小さいKp)-E(大きいKp)`、`追加コスト = C(大きいKp)-C(小さいKp)`。

1→2、2→2.5、2.5→3倍で、どれだけ誤差が減り、どれだけ追加のコストが生じたかを見る。

`改善1mあたりの追加コスト = 追加コスト/誤差改善量`。

最大誤差1m、RMS1mの改善を得るために追加した遷移回数または高度損失[m]。誤差が改善しない区間はnullとし、改善量が負だったことを別に残す。コストも下がった場合は負値を維持する。誤差がほとんど変わらないと比は大きくなるので、必ず元の差分と併読する。

観測終端の誤差は停止位相に影響されるため、改善単価には使用しない。この比で普遍的な最適Kpを定義しない。

## 一方的に劣る条件の確認

最大誤差（またはRMS）・遷移回数・追加高度損失の全てで他条件以下で、少なくとも一つが厳密に小さい場合、他条件がその条件より優位と記録する。
最大誤差基準とRMS基準は別に保存する。誤差とコストの重みは新たに仮定しない。

## 有限観測の限界

比較値は同じ30日または60日の保存サンプルから求める。短い静穏だけで収束と判定せず、残留速度、次回予測、観測内の再切替も確認する。
4点の値を結ぶ線は見やすくするためのもので、未計算倍率の挙動を保証する補間や最適化モデルではない。
