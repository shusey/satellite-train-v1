# 研究判断用サマリー

## 1. 今回何をしたか

Kp＝1倍と3倍の間の折衷点を調べるため、新たに2倍・2.5倍を計算した。速度への感度、姿勢変更の待ち時間、閾値、外乱、物理・数値条件は変えていない。既存1倍・3倍を再利用し、30日結果を確認してから、新規2条件だけを保存状態から60日へ延長した。

## 2. 最重要結果

- **30日では、Kpを上げるほど誤差が小さくなった。しかし60日では2.5倍が最も小さく、3倍で悪化した。** 改善は3倍まで単調には続かなかった。
- **60日の2.5倍は3倍より、最大誤差3.4%、RMS8.7%小さく、切替と追加高度損失は約33%少なかった。** 今回の主要指標では、3倍を使う利点が失われた。
- **2倍も低コストの候補になった。** 3倍より最大誤差は8.4%大きいが、RMSは1.6%小さく、追加高度損失は約42%少ない。
- **3倍の後半30日の切替増加は、2.5倍の約2倍だった。** ただし最短待ち時間で連続切替する極端な挙動は全条件で現れなかった。
- **2倍・2.5倍も再切替が続き、60日で収束は確認できなかった。** 少ない切替を「反応が終わった」と解釈しない。

## 3. 主要比較表

同じ60日間で比較。RMSは全期間・全間隔をまとめた平均的な誤差の大きさ。追加高度損失は、同じ外乱で全LOWにした場合より余分に失った21機平均の高度。

|Kp倍率|最大誤差 [m]|RMS [m]|切替数 [回]|追加高度損失 [m]|
|---:|---:|---:|---:|---:|
|1|107.82|31.48|586|13.21|
|2|71.24|24.94|1,066|24.04|
|2.5|63.47|23.13|1,216|27.42|
|3|65.69|25.35|1,822|41.09|

見るべき点は、2.5倍が3倍に近い精度を低コストで得るだけでなく、この60日では精度も上回ったこと。ただし1倍に比べれば、2.5倍も切替と追加損失が約2.08倍であり、低コストの1倍を全面的に置き換える結果ではない。

## 4. この結果をどう解釈するか

Kpを増やすと、位置ずれが育つ前に早く反応する。その一方、初回応答後に残った速度差は4条件でほぼ同じで、位置ずれを再び蓄積して次の反応を起こす仕組みは残った。3倍では後半の再反応が多くなり、早い初回応答が長時間の良さへそのままつながらなかった。

したがって、2.5倍を精度とコストの有力な折衷候補、2倍をより低コストの候補とする。ただし2.5倍の最大誤差は60日末に発生し、終了時誤差だけなら3倍の方が小さいため、観測期間による順位変化は残る。最適Kpや永久収束を証明した結果ではない。

## 5. 次に何をするべきか

1. **Kp＝2／2.5倍、Kd＝0.7／1倍の小規模2次元比較を優先する。** 今回のKd＝1倍を再利用すれば、新規計算は2条件だけ。残る速度差と再切替を減らせるか確認する。
2. **候補を絞った後、外乱位置などを1条件だけ変えて順位を確認する。** 今回の中央外乱だけで一般化しない。

さらに細かいKp単独掃引や、位置・速度の両方の感度を変える閾値変更は、現段階の第一優先にはしない。今回、上記の追加実験は実施していない。
