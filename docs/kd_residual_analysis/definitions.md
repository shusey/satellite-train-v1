# Kd単独変更の評価定義

## 固定条件とゲイン指定

software regression referenceの `tests/fixtures/regression_24h/config.yaml` を一次情報とする。Kd0 = 2/21600 = 9.259259259259259e-5 s^-1。今回のKdは0.3/1/3倍、すなわち2.7777777777777776e-5、9.259259259259259e-5、2.777777777777778e-4 s^-1。Kp = 1/21600² = 2.143347050754458e-9 s^-2。

従来のdesign_time_sを変えるとKpとKdが同時に変わる。そこでcontroller.kd_s_invという任意指定を追加した。未指定時の導出式・正規化設定の形式は従来どおり。Kp、dwell 300秒、slew 120秒、制御周期10秒、h_on 1.5e-7 m/s²、h_off 1.4e-7 m/s²、物理条件・外乱・積分器は固定する。

## 実装された制御判定量

間隔iは衛星iとi+1の間。e_i = a0(λ_(i+1)−λ_i)−d、v_i = de_i/dt = a0(n_(i+1)−n_i)。p_i = Kp e_i + Kd v_i。

q_1 = p_1、内側衛星ではq_j = p_j−p_(j−1)、q_N = −p_(N−1)。同じ差分演算をBと表せば、q_P = Kp B e、q_D = Kd B v、q = q_P + q_D。

LOWでq≥h_onかつdwell/遷移条件を満たすとHIGHを指令。HIGHでq≤h_offかつ同じ条件を満たすとLOWを指令。slew中は面積が線形に変化する。qは符号付きであり、|q|による判定ではない。

## 残留状態と分布

各衛星のLOW→HIGH→LOWを1局所cycleとする。終了はLOWへの姿勢変更完了時刻。直後の最初の保存サンプルを使い、sampling offsetも記録する。今回は保存周期10秒で完了時刻も格子上にある。

- V_res = max_i |v_i| [m/s]：全20間隔の物理的残留相対速度。
- 速度RMS = sqrt(mean_i v_i²)、速度絶対中央値 = median_i |v_i|。
- 起点/参加衛星の指標：それらの衛星に接続する間隔の和集合で評価。衛星自身の軌道速度ではない。
- Q_D,res = max_j |q_D,j| [m/s²]：制御信号。Kdを含むため、そのまま物理性能として倍率間比較しない。
- Q_D,res / Kd = max_j |(Bv)_j| [m/s]：衛星節点での速度差分。V_resと同じ量ではない。
- 符号付きe、v、q_P、q_D、q、modeは `cycle_end_states.npz` に保存。CSVのend_state_rowで行を参照する。

### 誤差が悪化する方向

e_i v_i > 0ならd(e_i²)/dt > 0、< 0なら減少、= 0なら瞬間の増減はゼロ。誤差悪化間隔割合 = count(e_i v_i>0)/20。ゼロ近傍の工学的許容差は設定せず厳密な符号を使うため、微小な丸め誤差も分類に入る。

補助指標として、sum_i max(e_i v_i,0)/sum_i |e_i v_i|を保存する。全積がゼロならnull。全間隔の平均二乗誤差変化率は2 mean_i(e_i v_i) [m²/s]。この重み付き割合と符号付き分布を併用し、小さい間隔を多数数えた割合だけで結論を出さない。各cycle終了時を1標本とする分布の中央値等は、時間平均ではない。頻繁な切替条件では標本数も増え、周囲が作動中の状態を多く含むため、条件間の1対1対応・因果効果量とは解釈しない。

## 局所cycle・時間群・全LOW境界

局所cycle番号は衛星ごとに独立しており、条件間の同番号は同じ周囲状態・時刻を意味しない。終了時に他衛星がHIGH/slew中なら全LOWの残留状態ではない。

時間群は既存14日baseline由来の固定分類間隔80953.6935537842秒で切替をまとめたもの。頻繁な応答では複数cycleを1群へまとめるため、群数を物理的な波数と同一視しない。

全LOW境界はLH指令からHL完了までの区間の重なりをまとめ、全衛星LOWかつpending遷移なしへ戻った時刻。分類間隔なしで求める。この活動区間が個別・部分列の切替を含む場合、全列を伝わる独立した波とは限らない。静穏後の起点指令と同区間の後続指令を分けてP/D比を集計する。

## 次回横断予測

同じB、e_dot=vなので、d(q_P)/dt = Kp Bv = (Kp/Kd)q_D。LOW境界t0以後、q_Dが一定かつ他の作動入力なしと近似すると、

q_j(t) ≈ q_P,j(t0)+q_D,j(t0)+(Kp/Kd)q_D,j(t0)(t−t0)。

初期q<h_onかつ傾きs_j=(Kp/Kd)q_D,j>0なら、予測横断時刻はt0+(h_on−q_P,j−q_D,j)/s_j。LOW側dwellの解除時刻と制御周期10秒の切上げを加えたものが予測指令時刻。全衛星の最早候補と実測の次回HIGH指令を比較する。

実測−予測を予測誤差 [s]、それを実測待ち時間で割ったものを相対誤差とする。後から別の衛星が作動、終了時に非LOW/pending、評価対象のD項変化が既存解析許容差10%を超える場合などは無効理由を残す。観測末まで次回指令がないものは右打切りとして扱い、予測精度の集計から除く。開始時点ですでにq≥h_onの場合は、将来の上向き横断の予測と区別し、主にdwell解除・制御格子を予測した結果としてstatusを別集計する。短い待ち時間では1制御周期10秒の差でも相対誤差が大きくなる。

同じ物理的vに対してs_jではKdが相殺される。ただし開始時のq_D自体はKdで変わるため、h_onまでの残りの距離は変わる。実シミュレーションではこの信号感度の変更が切替履歴を変え、その結果、残留速度も変わる。傾き係数の相殺だけでKdに影響がないとはいえない。baseline第1時間群の同一終了状態・同一dwell時計を0.3/1/3倍で評価した補助予測も保存する。これは物理再計算ではなく、この直接効果を切り分ける参考値。

## P/D分類と閾値・指令時刻

HIGH指令時と、直前のLOW区間における最後の連続したq≥h_on区間の初回サンプルを区別する。LOWに戻った時点ですでに閾値以上なら、新しい上向き横断とは記録しない。dwellがあるため、横断時刻と指令時刻は一致しない場合がある。サンプル間の厳密な横断時刻は求めていない。

Dの絶対値比 = |q_D|/(|q_P|+|q_D|)。|P|≥2|D|をP優勢、|D|≥2|P|をD優勢、その他を混合とする。全ゼロは別分類。2倍は後処理の分類設定であり物理モデルの閾値ではない。反対符号・相殺比 |q|/(|P|+|D|)も保存する。絶対値比は因果寄与率ではない。

## HIGH保持とコスト

HIGH完了＋300秒を制御周期へ切り上げた最早LOW指令候補で、q≤h_offを満たすか確認。満たさないものをh_offによる最初のgate阻止として数える。まだ帰還していないHIGHも含め、gateが観測外なら不明とする。完了cycleだけの集計は右打切りによる偏りがあるため避ける。

HIGH安定時間は面積がHIGHに固定された時間、HIGH equivalent timeは∫(A−A_LOW)/(A_HIGH−A_LOW)dt。120秒の上下slewとHIGH安定300秒なら1完了cycleのequivalentは420秒。

追加平均高度損失(t) = mean_j[a_allLOW,j(t)−a_control,j(t)] [m]。同一外乱・時刻・物理条件の全LOWケースを基準とし、正が制御による追加損失。円軌道モデルではh=a−R_Eなので長半径差と高度差は一致。controller無効時の物理軌道はKdに依存しないため、既存全LOW30/60日runを共用する。開始時からの平均損失mean[a(0)−a(t)]とは区別する。

全体RMSは全保存時刻・全間隔の sqrt(mean(e_i(t)²))。図の瞬間RMSは各時刻で間隔方向だけのRMS。終了時最大誤差は収束判定ではない。今回の既定settlingは既存の許容誤差50m、速度1mm/s、保持窓1800秒で有限観測末までの状態/切替条件を評価し、verification horizonを併記する。許容誤差等は既存の後処理設定で変更できる。永久収束は保証しない。
