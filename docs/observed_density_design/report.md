# 研究判断用サマリー

## 1. 結論

**現在の「+50%・幅100 km・1時間」は、3条件を組み合わせた現実的な設計外乱としては支持できません。** +50%の局所密度上昇自体は観測と整合します。しかし、今回よく近似できた構造は数百km以上であり、その構造の寿命が1時間だったとは確認できません。さらに現在の外乱は、地球上の構造を衛星が通過する設定ではなく、衛星列と一緒に移動して同じ衛星付近に作用する設定でした。この違いは長期誤差に直結し得ます。

## 2. 最も重要な観測結果

- 地磁気嵐2件と事前比較の計9日を解析。CHAMP高度は約388–420 kmでした。
- NRLMSIS 2.0比の密度偏差は最大+383%。これは広域的な嵐応答やモデル誤差も含み、「幅100 kmの局所上昇+383%」を意味しません。
- 100 km離れた軌道上の点を約13秒差で比べると、**400 km規格化密度の差／2点平均密度**は、嵐の期間の中央値約0.8%、95百分位約5.4–5.9%。大きい値もありましたが、同時刻の2衛星観測ではありません。
- Gaussian近似の採用条件を満たしたCHAMPの窓は151件。見かけの幅は318–2507 km、中央値912 kmでした。幅100 kmは約1.3サンプル間隔しかなく、今回の方法では確実な幅を決められません。
- GRACE A/Bの約216–226 km間隔の比較も密度構造の空間差を示唆しました。ただし緯度3度で平均されたデータなので、100 km級の直接証拠には使えません。

## 3. 現在の人工外乱との比較

| 項目 | 観測・文献との照合 | 判定 |
|---|---|---|
| 最大+50% | 局所背景から約+44%、+49%の近似候補を抽出。文献にも約+50%の例 | 強いが観測範囲内 |
| FWHM 100 km | 今回の強い候補は404、536 km。100 kmは十分に解像できない | 現設定を支持する証拠不足 |
| 約1時間 | 数時間の広域応答は文献にあるが、個別の狭い構造の寿命とは別 | 未確定 |
| 3条件＋列との共移動 | 同じ衛星へ長く作用する観測根拠がない | 大幅な修正が必要 |

広い上昇は共通高度低下を、急な勾配は間隔変化を起こします。**最大密度より100 kmでの密度差と作用履歴が重要**です。

## 4. 新しい設計外乱候補

候補は、事前比較の代表として**+45.6%・1653 km**、強い観測例として**+43.7%・536 km**、近似した100 km差が最大の例として**+49.3%・404 km**です。いずれも地域的な背景からの上昇率です。最後の例の背景密度は400 km相当で約1.23×10⁻¹¹ kg/m³と高く、幅が広くても絶対密度差は現在の人工外乱に匹敵します。

**寿命は未同定です。** 最初の候補も気候学的なnominalではなく、選別イベントだけから発生確率付きの設計条件は確定しません。

## 5. 研究意義への影響

密度の空間差を研究する根拠は得られました。一方、現在の人工外乱による無制御約7.97 kmという結果を、そのまま実環境の制御必要性へ結び付ける根拠は弱まりました。Gaussianは機構解析用に残し、観測検証用とは区別すべきです。

## 6. 次にやること

1. 地球に対する構造の移動を、衛星列との相対移動へ変換する。
2. 複数軌道・高分解能の比較で、候補の寿命と推定密度の品質を確認する。
3. 条件確定後、短時間の全LOW対制御比較を行い、必要性があれば長時間化する。
