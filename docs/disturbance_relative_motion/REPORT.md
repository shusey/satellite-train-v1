# 研究判断用サマリー

## 1. 結論

**大きな間隔誤差が生じたのは共移動ケースでした。** 全LOWで2日間観測した最大誤差は、地球固定で約0.63 mm、TAD伝播で約0.77 mm、初期衛星速度で共移動させた場合で約4.33 kmでした。今回の「時間変化しない構造を全機が一度横切る」条件は、指定された**パターンA**に近い結果です。ただし、共移動では2日後も外乱が作用中であり、4.33 kmを「外乱終了後の残留誤差」とは呼べません。

## 2. 主要比較表

振幅49.3%、幅403.7 km、21機・100 km間隔、全LOWを固定。積算密度差は、衛星別の外乱増分積分の最大値−最小値です。

| ケース | 1機の相対通過時間 | 2日間の積算密度差 [kg·s/m³] | 通過1日後の最大残留速度 | 2日間最大間隔誤差 |
|---|---:|---:|---:|---:|
| 地球固定 | 52.64秒 | 4.48×10⁻¹⁶ | ほぼ0（数値値1.91×10⁻¹¹ m/s） | 0.000630 m |
| TAD・730 m/s | 58.18秒 | 5.47×10⁻¹⁶ | ほぼ0（数値値1.62×10⁻¹¹ m/s） | 0.000768 m |
| 初期速度で共移動 | 通過せず・作用継続 | 3.05×10⁻⁷ | 未定義。2日後・作用中は0.0500 m/s | 4329.82 m |

通過後の速度の細かな符号や大小は計算精度の範囲です。短い通過区間で刻みを変え、物理的に意味のある残留速度を検出したとは言えないことを確認しました。通過ケースの30日誤差は速度一定の参考予測でも約1 mm未満でしたが、30日を実計算した結果ではありません。

## 3. なぜ違ったか

地球固定・TADでは、各衛星はほぼ同じ密度の山を順番に通ります。通過中には速度差が生まれますが、後続機も同じ山を通ると、積算抗力の差はほぼなくなりました。一方、共移動では中央付近に密度上昇が居続け、中央と端部で受ける抗力が積み重なって違ってきます。**3ケースの最大瞬間密度差はほぼ同じだったため、瞬間値より積算量が、今回の大きな結果の違いを説明しています。**

## 4. 従来モデルへの評価

旧ケースは保存データで、外乱後の速度差が約1.47 mm/s、60日最大誤差が7.97 kmでした。今回の結果は、特定衛星へ偏って作用し続ける共移動仮定が、その主要因だった可能性を支持します。ただし旧ケースとは幅と時間窓も違うため、旧結果への寄与を完全分離したわけではありません。従来モデルは**機構解析とstress test用に残し、現実の代表外乱としては採用を保留**するのが妥当です。

## 5. 研究意義への影響

今回の単発・定常通過モデルでは、地球固定・代表TAD速度の外乱に対して、100 m級誤差を防ぐ制御の必要性は支持されません。長期誤差は共移動に強く依存しました。ただしこれは、地球自転や再遭遇を含まない一次元近似で、背景密度も従来値です。振幅・幅と伝播速度は別イベントから採用しており、観測イベントの再現や、実環境全般での制御不要を示す結果ではありません。

## 6. 次にやること

1. 全列の通過時間約4.4–4.8分に対して、構造の成長・減衰がどの程度速いかを観測から制約する。
2. その根拠で寿命・時間変化を追加し、積算抗力差が残る条件を少数ケースで確認する。
3. 軌道との方向・地球自転・再遭遇の近似を見直してから、制御必要性の比較へ戻る。

ユーザー指定の第一候補と一致し、100 km離れた点の差を大きくする保存済み候補であるため採用しました。他イベントとの振幅・幅掃引は行っていません。Gaussianは形状近似であり、実大気がGaussianであるという主張ではありません。

### TAD速度

Bruinsma & Forbes (2007), “Global observation of traveling atmospheric disturbances (TADs) in the thermosphere”, GRL 34, L14103,
[原論文](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2007GL030243)。
2003-05-29のCHAMP約400 kmの観測から、北半球昼側でオーロラ域から赤道方向へ伝播する初めの5つのTADについて、約730 m/sが報告されています。

今回はその速度を衛星進行方向へ投影した代表値として使います。実際のTADが常に軌道と同方向であるとは仮定しません。11月のGaussian候補と5月の速度は**別イベントの設計要素**であり、振幅49.3%・幅403.7 km・速度730 m/sという組合せが同時に観測された証拠ではありません。

### 固定条件と違いの確認

既存24時間software referenceの設定を元にしました。高度400 km、N=21、間隔100 km、質量4 kg、Cd=2.2、LOW面積0.01 m²、基準密度3.584968×10⁻¹² kg/m³、スケールハイト58310 m、RK4最大刻み2 s、保存10 sです。初期状態は全ケース同一、制御は全ケース無効です。ゲイン・姿勢関連設定も保存上は基準のままです。

採用イベントの400 km局所背景密度は約1.235×10⁻¹¹ kg/m³でしたが、今回は置換していません。外乱移動だけを比較するため、従来の指数背景を維持しました。したがって観測嵐の絶対抗力を再現した実験ではありません。NRLMSISも今回の新規runには使っていません。

3ケースの入力差分は、`disturbance.propagation_speed_m_s` と、それから機械的に算出する `disturbance.center_s_m` だけです。その他の物理・数値設定が一致することを実行時に検査し、差分一覧をstudy.jsonへ保存しました。背景・積分器等の固定セクションは元baselineとも照合済みです。

## B. 座標・位相合わせ・通過の定義

新しい選択肢は `disturbance.type=earth_track_gaussian` です。

```
x_j(t) = a0 * lambda_j(t)
s_c(t) = s_c0 + v_dist * t
rho_j = rho_bg(a_j) * [1 + A exp(-(x_j-s_c)^2/(2 sigma^2))]
```

衛星の位置は実際の平均軌道状態から取り、外乱中心は独立した一定速度で進めます。衛星列の平均位置へ中心を追従させません。位置は周回で折り返さない一次元軌道座標です。地球固定ケースはこの座標に固定した、一度通過する地球上の構造の近似です。地理緯度経度、地球自転、周回ごとの再遭遇を再現する実装ではありません。

基準速度は現在のモデルから `v_sat,0=a0*n0=7668.558175407054 m/s`。
中央機が構造中心と重なる予定時刻を、既存設定の10800 sに揃えました。

```
s_c0 = (v_sat,0 - v_dist) * 10800
```

これは任意の初期位相が通過外乱を途中で切り取ってしまうことを避けるための規則です。外乱中心の初期位置はケース間で違いますが、独立した比較因子として変更したものではありません。共移動だけは最初から中央付近へ作用しており、「外乱前」はありません。完全に同じ初期中心位置で、通過2ケースの全通過と厳密共移動の中央曝露を同時に実現することはできません。

時間窓は使いません。新選択肢では既存設定の `start_time_s`・`duration_s` は外乱をオン／オフせず、旧形式との共存のため残っています。

| 項目 | 地球固定 | TAD | 初期速度で共移動 |
|---|---:|---:|---:|
| v_dist [m/s] | 0 | 730 | 7668.5582 |
| 初期v_rel [m/s] | 7668.5582 | 6938.5582 | 0 |
| FWHM / abs(v_rel) [s] | 52.6388 | 58.1768 | 定義不可 |
| 列長2000 km / abs(v_rel) [s] | 260.8052 | 288.2443 | 定義不可 |
| 全機通過終了判定 [s] | 11070 | 11100 | 2日内に成立せず |

列全体は約4.4–4.8分差で同じ構造に出会います。構造がこの間に変化するなら、全機が同じ積算量を受ける結論は変わり得ます。

Gaussianに厳密な終端はありません。ここでは全機が中心の前方6sigma以上に進み、その後もそこから戻らない最初の保存時刻を通過終了とします。相対増分／Aはexp(-18)以下です。判定分解能は10 s。

共移動は初期の基準速度へ一致させた**一定速度**です。実際の衛星速度は高度低下で変わるため、その後の相対速度が厳密にゼロとは限りません。2日間は構造内に留まっており、以後も永久に共移動することは保証していません。

## C. 積算量の定義と軌道状態との関係

```
J_rho,j = integral rho_j dt                         [kg·s/m³]
J_delta,j = integral (rho_j - rho_bg(a_j)) dt         [kg·s/m³]
J_drag,j = integral [-Cd*A_LOW*rho_j*mu/(2*m*a_j)] dt [m/s]
```

外乱増分の背景は**同じ時刻・同じ実際の衛星高度**で評価します。別の無外乱軌道との差ではありません。増分抗力の積分も同じ抗力係数でrhoをrho−rho_bgへ置き換えます。抗力積分は進行方向に対して負の符号です。

積分は10秒保存値の台形積分ではなく、元のRK4各段階へ受動的な積算状態を追加して行います。積算状態は物理状態へ戻りません。既存の物理微分関数とRK4をそのまま再利用します。

既存の平均円軌道モデルは、

```
da/dt = -rho*Cd*A_LOW/m * sqrt(mu*a)
dlambda/dt = sqrt(mu/a^3)
de_i/dt = a0 * (n_(i+1)-n_i)
```

です。抗力で高度が下がると平均運動が速くなるため、負の抗力積分を、間隔速度へそのまま同じ符号で足すことはできません。
小さい高度差の一次近似では、

```
de_i/dt ≈ -3 * (J_drag,i+1 - J_drag,i)
```

となります。これは抗力で生じる軌道半径差が、平均運動の差へ変わる関係です。増分抗力だけを使う場合は背景の状態依存分を省略した近似です。共移動の最大速度差に対するこの近似の差は約0.16%でした。通過ケースでは両方ともほぼゼロなので、細かな相関を評価しません。

全LOWの同じ初期半径に対して、さらにこのモデルの厳密な積分関係は、

```
sqrt(a_j(t)) = sqrt(a0) - (Cd*A_LOW/(2*m))*sqrt(mu)*J_rho,j(t)
```

です。全密度曝露から最終軌道半径を再構成し、そこから速度差を評価できます。再構成半径と実計算の差は、通過ケース約1.2×10⁻⁸ m以下、共移動約2.2×10⁻⁷ m。速度差の再構成誤差は共移動でも約5.5×10⁻¹⁰ m/sでした。積算量から状態への関係を、このモデルに沿って確認しています。

### 短い精度確認と30日参考予測

2日runは再計算せず、位相を450 sへ移した900 sの短い通過検証だけを、4 / 2 / 1 s刻みで行いました。2 sと1 sの終了時誤差差は地球固定2.11×10⁻⁸ m、TAD3.16×10⁻⁸ m。終了時速度差の比較はそれぞれ4.56×10⁻¹¹、4.26×10⁻¹¹ m/sで、刻みを細かくしても微小速度の符号は安定しませんでした。

通過後3時間から2日までの直線近似の誤差成長率も、最大約1.8×10⁻¹¹ m/sで、数値精度付近です。物理的な長期成長を検出したとは言えません。

`e(30d)=e(2d)+de/dt(2d)*(30d−2d)` の速度固定予測は地球固定0.000676 m、TAD0.000807 mでした。数値ノイズを含む点推定であり、30日物理run、厳密上限、永久安定性の証明ではありません。参考に10⁻⁹ m/sという観測値より大きい速度差を仮置きしても、28日分は約2.4 mmです。この仮置きは誤差保証ではなく、尺度を読むための感度です。今回の主問いには2日と短い検証で十分な差があり、7日・30日への追加runは実施していません。

## E. 旧外乱との参考比較

新規計算せず、既存の旧全LOW・24時間／60日runを読みました。両入力が観測時間だけ異なることも照合済みです。

- +50%、FWHM100 km、半余弦1時間、基準軌道と共移動。
- J_deltaの最大−最小：約3.2272×10⁻⁹ kg·s/m³。保存10 s密度から台形積分。
- 24時間最大誤差108.4536 m、残留最大gap速度0.00147053 m/s。
- 60日最大誤差7968.8550 m、終了時最大gap速度0.00161808 m/s。

約1.47 mm/sなら1日で約127 mを積み上げる尺度です。外乱終了後もその速度差が残ることが、数kmへの成長を説明します。新しい通過ケースでは積算差と残留速度がほぼ消えました。

今回、振幅・幅を固定した3ケースでは移動速度による大きな違いが確認できました。一方、旧ケースとの比較には幅100 km対404 km、時間窓1時間対なし、継続曝露の長さの違いもあり、旧7.97 kmを「共移動だけで何%」と分解することはできません。時間窓と狭い幅は偏った曝露量を定める要素で、共移動はその偏りを同じ衛星付近に留める要素です。

## G. 観測されたこと・解釈・未確定

**観測されたこと（今回の数値実験）**：定常構造の全通過では最終曝露量がほぼ揃い、残留速度は検出できる尺度ではありませんでした。共移動では曝露が偏り、2日間でkm級誤差を生じました。

**そこから言えること**：既存モデルの長期誤差を説明するには、瞬間の密度ピークより、衛星ごとに異なる積算抗力と、その結果の平均運動差を重視する必要があります。共移動仮定はこの偏りを強め得ます。パターンAが今回の主比較に最も近い結果です。

**まだ言えないこと**：実際のTAD、有限寿命の構造、繰返し遭遇、地球自転・軌道との方向、より高い背景密度でも同じ小ささになるとは保証していません。実環境の制御不要、永久安定、旧結果の原因比率は断定できません。共移動ケースは外乱終了後の実験ではなく、継続作用のstress testです。

## H. 最重要10問への回答

1. **地球固定の積算密度差**：4.48×10⁻¹⁶ kg·s/m³。衛星平均曝露の約4.53×10⁻⁶で、ほぼ同じ曝露でした。
2. **TADの積算密度差**：5.47×10⁻¹⁶ kg·s/m³。平均曝露の約5.00×10⁻⁶です。
3. **共移動の積算密度差**：2日間で3.05×10⁻⁷ kg·s/m³。作用継続中です。
4. **残留相対速度**：通過2ケースはほぼ0、数値値は約10⁻¹¹ m/s。共移動では通過後を定義できず、作用中の最大値0.0500 m/sです。
5. **長期誤差**：通過ケースは2日間1 mm未満。30日の速度固定予測も約1 mm未満ですが実計算ではありません。共移動は2日で4.33 kmでした。
6. **どの密度指標が説明するか**：今回の条件差は積算量が説明します。最大瞬間密度差はほぼ同じで、大小の順位を説明しません。
7. **旧7.97 kmの主要因か**：偏った曝露を長く保つ共移動が主要因だった可能性を支持。ただし幅・時間窓の寄与を完全分離できていません。
8. **現実的TAD速度で制御が必要か**：今回の一度の定常通過では支持されません。現実の継続的・時間変動大気への判断は別です。
9. **旧モデルの位置付け**：機構解析・stress testとして残し、観測に裏付けられた代表環境として使うことは保留します。
10. **寿命・時間変化を導入する価値**：あります。数分の列通過中に形が変わると等しい積算曝露が崩れるため、次に調べる合理的な因子です。根拠なく1時間へ戻してはいけません。
